Document 1: Adding Raw Materials – Manual Feed
Title: How to Add Manually Fed Raw Materials in IDS Edge Batching Software (RDC)

Tags: raw material, manual feed, IDS Edge, batching software, RDC, UTLFNE, FIBRE, FIBREPE, MSILICA, EPSTB, skip bucket, aggregate conveyor, mixer

Description:
This guide explains how to add new raw materials that are fed manually in the IDS Edge batching software for RDC (Ready-mix/Dry mix concrete) plants. Manual feeding refers to the process where materials are fed by hand — directly into the skip bucket, aggregate conveyor, or mixer — without the use of any conveyor, motor, screw conveyor, or weighing scale.

Examples of manually fed raw materials include:

UTLFNE (Ultra Fine)
FIBRE
FIBREPE (Fibre Polyethylene)
MSILICA (Micro Silica)
EPSTB (EPS beads/stabilizer)
Use this guide when: You need to configure a new raw material in IDS Edge that does not use automated equipment for feeding and is added manually by an operator.

Reference Video: https://youtu.be/CIi0asOp05o

Document 4: Running Two BINs/SILOs Simultaneously (Coarse Feeding / Parallel Feed)
Title: How to Run Two BINs/SILOs Simultaneously (Parallel / Coarse Feeding) in IDS Edge Batching Software (RDC)

Tags: parallel feed, coarse feeding, two silos, simultaneous bins, IDS Edge, batching software, RDC, cement silo, reduce feeding time, dual silo, batch speed

Description:
This guide explains how to configure and run two BINs or SILOs simultaneously (in parallel) in IDS Edge for RDC batching. This feature is also known as Coarse Feeding. Running two bins/silos at the same time — for example, two cement silos in parallel — reduces the total feeding time per batch and increases throughput.

Key concepts:

Two silos feeding the same material at the same time
Commonly used for CEMENT when a single silo is slow to dispense
Also referred to as Coarse Feeding in IDS Edge
Use this guide when: You want to speed up batching by enabling two silos or bins to feed the same material simultaneously.

Reference Video: https://youtu.be/bYw09ubvZtM
